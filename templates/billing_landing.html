Вопросы

Частые вопросы

Где взять ключ для подключения?
В разделе «Подключения» личного кабинета: там ключ vpn://, QR-код и файл конфигурации для приложения.
Сколько устройств можно подключить?
Лимит устройств указан в составе каждого тарифа на странице «Тарифы». Для каждого устройства выдаётся отдельный ключ.
Как продлить подписку?
Откройте «Тарифы» и выберите новый срок: он добавится к текущей дате окончания подписки.
{% if trial_public %}
Есть ли пробный период?
Да, {{ trial_days }} дней. Активация доступна в личном кабинете, если пробный период ещё не использован.
{% endif %}
Что происходит после оплаты?
Оплата проходит на странице платёжного сервиса. После возврата в кабинет откройте «Подключения»: там ключ и QR-код для приложения Amnezia.
